QGIS MCP V1 → V2 架构升级

V1: 自定义 TCP socket 直连 QGIS 插件 ❌ 不符合 MCP 标准
V2: FastMCP 标准框架 + TCP 桥接 QGIS 插件 ✅ 符合 MCP 规范

一、问题在哪

V1 的核心问题

V1 号称是 MCP，但实际做法是：

  1. Hermes 直接通过 raw TCP socket 连到 QGIS 插件的 9876 端口
  2. 自己构造 JSON-RPC 2.0 格式的消息（手动拼 {"jsonrpc":"2.0","method":"tools/call",...}）
  3. 自己处理 TCP 分包、缓冲、解析
  4. 没有使用 MCP SDK，没有标准传输层

类比：这就像说自己做了一个 RESTful API，但用的是自定义 TCP 协议，没有用 HTTP。GET/POST/PUT/DELETE 才是 RESTful 的标准，不是自己发明一种格式然后说"我这就是 REST"。

V1（错误做法）：

Hermes ──[raw TCP socket]──► QGIS 插件 :9876
        │                     │
        └── 手动拼 JSON-RPC ──┘   └── 自己解析
        ❌ 没有 MCP SDK
        ❌ 没有标准传输层
        ❌ 没有工具 schema 注册
        ❌ 任何标准 MCP 客户端都不认

二、V2 怎么改

V2 的正确做法
  1. MCP Server（FastMCP 框架）：对外暴露标准 MCP 接口，LLM 客户端通过 stdio/SSE/HTTP 连接
  2. TCP Client：MCP Server 内部通过 TCP 连接 QGIS 插件，转发命令
  3. QGIS 插件：保持不变，已经在做 JSON-RPC 2.0 协议

这就像做 RESTful API：用 HTTP 协议 + 标准 HTTP 方法 + JSON 格式。MCP 的标准就是：JSON-RPC 2.0 + stdio/SSE/HTTP 传输 + 标准工具注册。

V2（正确做法）：

LLM Client (Claude/Cursor/Hermes)
    │
    │ stdio / SSE / HTTP（MCP 标准传输层）
    │ JSON-RPC 2.0（MCP 标准协议）
    ▼
┌─────────────────────────────────────────┐
│  FastMCP Server (server/server.py)       │
│  ├── @mcp.tool() 注册工具（自动生成 schema）│
│  ├── MCP SDK 处理协议                    │
│  └── TCP Client 转发到 QGIS 插件         │
└──────────────────┬──────────────────────┘
                   │
                   │ raw TCP socket（内部通信）
                   │ JSON-RPC 2.0（QGIS 插件原生协议）
                   ▼
┌─────────────────────────────────────────┐
│  QGIS 插件 (plugin.py)                   │
│  ├── QTimer 25ms 主线程安全               │
│  ├── TCP Server 监听 :9876               │
│  └── PyQGIS API 执行 GIS 操作           │
└─────────────────────────────────────────┘

✅ 标准 MCP 协议
✅ 标准 MCP 传输层
✅ 标准工具 schema
✅ 任何 MCP 客户端都能连

五、工具注册对比

V1：手动定义 schema（❌ 不是 MCP 标准）

# V1 在插件端手动定义工具 schema
MCP_TOOLS = [
    {
        "name": "get_layers",
        "description": "List all layers",
        "inputSchema": {"type": "object", "properties": {}}
    },
    # ... 18 个工具手动列举
]

# 客户端直接通过 TCP 发送 tools/list 请求获取

V2：FastMCP 自动注册（✅ MCP 标准）

# V2 使用 @mcp.tool() 装饰器自动注册
@mcp.tool(
    title="Get Layers",
    description="List all layers in the current QGIS project with their properties."
)
async def get_layers(ctx: Context) -> list[TextContent]:
    result = _call_tool("get_layers", {})
    return [TextContent(type="text", text=json.dumps(result, indent=2))]

# FastMCP 自动从函数签名生成 JSON Schema
# MCP SDK 自动处理 tools/list 响应

六、运行方式

安装依赖
pip install mcp
# 或使用 uvx
uv pip install -e /path/to/qgis-standard-mcp
stdio 模式（Claude Desktop / Cursor）
python run_server.py
# 或
python -m server
SSE 模式（远程访问）
python run_server.py --transport sse --sse-port 8080
# 客户端连接 http://localhost:8080/sse
HTTP 模式（Streamable HTTP）
python run_server.py --transport http --sse-port 8080
